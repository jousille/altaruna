# Alta Runa – сайт

Статический сайт для GitHub Pages: главная, «Купить», «Гайд по рунам», «Статьи», страница статьи.

## Как устроена публикация

Сайт собирается автоматически: после каждой правки в ветке `main` GitHub Actions запускает
`scripts/build.mjs`. Скрипт берёт `data/products.js` и `data/articles.js` и делает:

- отдельную готовую страницу для каждой статьи (`/articles/<id>/`) и каждого товара (`/products/<id>/`);
- заполненные главную, каталог, статьи и гайд – чтобы поисковики видели текст без JavaScript;
- `sitemap.xml`, `robots.txt`, `404.html`, превью для соцсетей и разметку schema.org (товар с ценой, статья с датой).

Ход сборки виден на вкладке **Actions** репозитория. Сайт обновляется через 1–2 минуты после правки.

Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

## Что где менять

| Что | Файл |
|---|---|
| Ссылки на Авито, Telegram, Instagram | `data/products.js` – блок `ALTA_CONFIG` в начале |
| Товары (название, цена, руна, камень, фото, ссылка на объявление) | `data/products.js` |
| Статьи | `data/articles.js` |
| Гайды: ссылка на бесплатный PDF, ссылка на оплату и цена платного | `data/products.js` – блок «ГАЙДЫ» в `ALTA_CONFIG` |
| Картинка-превью гайда | `images/guide-preview.png` – замените файлом с тем же именем |
| Цвета, шрифты | `assets/style.css` – блок `:root` в начале |
| Дизайн-система: палитра, шрифты, отступы, правила | `design-system/` (на сайт не публикуется) |
| Тексты главной («О бренде», слоганы) | `index.html` |

Редактировать можно прямо на GitHub: открыть файл → значок карандаша → Commit changes.

## Фото

Создайте папку `images` (Add file → Upload files, перетащите фото вместе с папкой) и укажите путь в товаре:
`image: "images/fehu-bracelet.jpg"`. Лучше всего – вертикальные фото 4:5, до 300 КБ.
Если фото нет, на карточке рисуется руна на «каменном» фоне.

У каждого товара есть своя страница (`product.html?id=...`) – открывается по клику на фото или название.
Чтобы там была галерея, перечислите фото в `images`, а блоки «О руне», «Состав», «Размер», «Уход» – в `details`
(пример – браслет «Иса» с аквамарином в `data/products.js`).

## Новая статья

Скопируйте любой блок `{ ... },` в `data/articles.js`, вставьте в начало списка и поменяйте:
`id` (латиницей – это адрес статьи), `title`, `category` (`runes` / `stones` / `tarot`), `date`, `excerpt`, `body`.
Статья сама появится в списке, на главной и в «Читайте также».

## Гайды

1. **Бесплатный гайд по рунам.** Создайте папку `guides` и загрузите туда PDF под именем `alta-runa-guide.pdf`
   (или укажите другое имя в `GUIDE_FREE_URL`).
2. **Платный гайд «Руны и камни».** В `GUIDE_FULL_URL` – ссылка, где его покупают, в `GUIDE_FULL_PRICE` – цена.

## Домен altaruna.ru

1. У регистратора домена добавьте DNS-записи:
   - четыре записи **A** для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись **CNAME** для `www` → `jousille.github.io`.
2. **Settings → Pages → Custom domain** → `altaruna.ru` → Save.
3. Когда проверка пройдёт (от нескольких минут до суток), поставьте галочку **Enforce HTTPS**.

## Поисковики

1. Яндекс Вебмастер (webmaster.yandex.ru) и Google Search Console – добавьте сайт `https://altaruna.ru`.
2. Подтвердите права: проще всего через DNS-запись TXT у регистратора.
3. Отправьте карту сайта: `https://altaruna.ru/sitemap.xml`.
